# Vavavoom: Custom USB-C MIDI Keypad

## Overview
Vavavoom is a custom-designed USB-C MIDI keypad built for interactive music creation and Digital Audio Workstation (DAW) control. Designed entirely in KiCad, it puts music production hardware right at your fingertips using mechanical switches, a rotary encoder, and a custom capacitive touch strip.

## How It Works
* **Microcontroller:** Powered by the Waveshare ESP32-S3-Zero, which handles USB connectivity and processes user inputs.
* **Mechanical Switches:** Tactile keys using Kailh Choc switches for triggering notes or shortcuts.
* **Rotary Encoder:** An Alps EC11 encoder used for volume control, scrolling, or parameter adjustments.
* **Capacitive Touch Strip:** A custom 7-pad touch interface connected to the ESP32's touch pins to act as a pitch bend or mini touch keyboard.
